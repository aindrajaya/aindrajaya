### Arista Indrajaya — Senior React Performance Engineer

**I fix what AI-generated code breaks.**

AI coding tools help teams ship SaaS products fast. The code they generate often makes the product slow: pages that load late, clicks that lag, screens that freeze on mid-range phones. I find what's causing it and fix it, without rewriting your app.

#### What I work on

- **Slow page loads (LCP):** render-blocking resources, oversized bundles, unoptimised images and fonts
- **Laggy interactions (INP):** long tasks, unnecessary re-renders, heavy work moved off the main thread
- **Core Web Vitals regressions** in React and Next.js apps, especially code written with Cursor, v0 or Copilot

#### How I work

Async by default. You get a recorded performance-trace walkthrough and a written fix plan, prioritised by impact on real users. No calls needed.

#### Stack

React · Next.js · TypeScript · Node.js · Web Workers · Chrome DevTools · Lighthouse · Vercel · Cloudflare
